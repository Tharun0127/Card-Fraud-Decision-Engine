# Data dictionary

Generated by `src/data/profile.py` from the merged labelled data (`train_transaction.csv` left-joined to `train_identity.csv` on `TransactionID`). Regenerated on every pipeline run; do not edit by hand.

- Rows: 590,540; raw columns after join: 434

- Share of transactions with an identity record: 24.4%

## Important caveats

- `TransactionDT` is a seconds offset from an unknown reference. It is treated as an ordering index only. Hour-of-day features derived from it assume the reference is midnight, which is unverified.
- `isFraud` reflects reported chargebacks, with propagation to later transactions on the same account. It is not confirmed fraud, and label maturity near the end of the data is unknown.
- Most columns are masked by the provider. Meanings below are family-level.
